# Maminin Yeri

Arsin / Trabzon'daki **Maminin Yeri** için tek sayfalık, statik web sitesi.

- Menü (imza lezzet: hamburger + patates), içecekler, çalışma saatleri, konum
- WhatsApp ile sipariş formu (sunucu yok; sipariş müşterinin kendi WhatsApp'ında hazır mesaj olarak açılır)
- Saf HTML / CSS / JS, derleme adımı yok

## Yerelde çalıştırma

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Alan adı

Alan adı alındığında `index.html` başındaki **SITE_URL AYARI** bloğunu güncelleyin.

Görseller yapay zekâ ile üretilmiş temsilî görsellerdir.
